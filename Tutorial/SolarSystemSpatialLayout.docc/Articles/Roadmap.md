# Roadmap

현재 튜토리얼은 Full Space, 밤하늘, 태양과 여덟 행성의 정적 배치, 원형 궤도선까지 설명합니다. 아래 기능은 아직 앱 코드에 없으며 후속 구현 순서만 제안합니다.

## 1. Mixed에서 Full로 전환

현재 `TutorialApp`의 Immersive Space는 `.full`만 허용합니다. Mixed 단계를 추가하려면 선택 가능한 스타일 범위에 `.mixed`와 `.full`을 포함하고, 어느 시점에 스타일 상태를 변경할지 정의해야 합니다.

고려할 상태:

- 현재 ImmersionStyle 선택
- 공간이 열리는 중인지 여부
- Full Space로 전환할 준비가 되었는지 여부

## 2. 공전 상태 분리

현재 `PlanetConfiguration.orbitAngle`은 초기 위치입니다. 설정 데이터는 그대로 두고, 실행 중 변화하는 각도를 별도의 상태 모델로 분리하는 것이 좋습니다.

필요한 데이터 후보:

- 행성 식별자
- 기준 공전 속도
- 현재 공전 각도
- 애니메이션 시작 시간
- 일시 정지 여부

## 3. 시간과 속도로 각도 계산

프레임마다 위치를 직접 저장하기보다, 시작 시각과 경과 시간으로 현재 각도를 계산하면 중단과 재개를 다루기 쉽습니다. 각 행성의 속도를 시각적으로 압축해 사용자가 차이를 알아볼 수 있게 하되, 실제 천문학적 비율과 시각화용 배율을 구분해서 기록해야 합니다.

계산 개념:

```text
현재 각도 = 초기 각도 + 경과 시간 × 행성별 각속도
```

계산한 값을 기존 `.solarOrbit(radius:angle:)`에 전달하면 커스텀 Layout이 새 좌표를 계산할 수 있습니다.

## 4. 자전과 자전축

공전 레이아웃 회전과 행성 자체의 자전을 분리해야 합니다. 공전은 부모 레이아웃의 위치를 바꾸고, 자전은 각 `PlanetModelView`의 시각적 회전을 바꿉니다. 행성별 자전축 기울기와 자전 속도를 설정 데이터로 추가할 수 있습니다.

## 5. 명왕성 배치와 탈출

현재 RealityKitContent에는 Pluto 에셋이 없고 `PlanetConfiguration.staticLayout`에도 명왕성이 없습니다.

먼저 해야 할 작업:

1. Reality Composer Pro에서 Pluto 모델을 생성하거나 사용 권한이 확인된 에셋을 가져옵니다.
2. RealityKitContent에서 `Model3DAsset(named: "Pluto", in:)`으로 로드되는지 확인합니다.
3. 명왕성의 초기 크기, 궤도 반지름과 각도를 설정합니다.
4. 일반 행성 배치와 탈출 상태를 구분합니다.

탈출 애니메이션에 필요한 상태 후보:

- 탈출 시작 여부
- 투명도
- 궤도 레이아웃에서 벗어난 3D 오프셋
- 애니메이션 진행률

투명도 변화와 3D 이동을 같은 진행률로 제어하되, 명왕성이 커스텀 궤도 Layout에 계속 참여할지 탈출 순간 별도 오버레이로 옮길지 먼저 결정해야 합니다.

## 6. 사용자 시점 변화

행성 배치가 안정된 뒤 전체 태양계를 보는 시점과 특정 행성을 가까이 보는 시점을 설계합니다. Full Space에서 콘텐츠를 갑자기 사용자 가까이 이동시키면 불편할 수 있으므로, 이동 거리와 속도를 실기기에서 검증해야 합니다.

## 완료 기준

후속 단계마다 다음을 확인합니다.

- 정적인 초기 배치가 유지되는가
- 행성별 속도 차이가 보이는가
- 각도가 360도를 넘어도 자연스럽게 이어지는가
- 궤도선과 행성 위치가 일치하는가
- 명왕성 탈출 후 다른 행성의 레이아웃이 의도대로 유지되는가
- 시점 변화가 불편함을 유발하지 않는가

현재 구조는 <doc:Architecture>에서, 실행 환경과 에셋 조건은 <doc:Requirements>에서 확인할 수 있습니다.
